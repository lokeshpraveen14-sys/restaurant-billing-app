Chapter 01

Introduction and System Overview

What this software does and how it is structured

The Railway Coach Kerala Restaurant Management System is a complete, end-to-end software solution built to handle all aspects of a restaurant business — from taking orders at the table to closing the books at the end of the month. This guide covers every single module in detail so that the owner, manager, cashier, waiter, and kitchen staff can all use the software with confidence.

The software runs in a web browser and is accessible from any device including tablets, computers, and smartphones. All data is saved to a central cloud database in real time, so every device at the restaurant sees the same up-to-date information simultaneously.

What This System Covers

Front of House

Table management, order taking, billing, bill history, head count tracking

Kitchen Operations

Kitchen display system, order queuing, status updates, KOT management

Back Office

Menu management, inventory, purchase entries, vendor management, reports

HR and Payroll

Staff records, salary management, advance payments, bank account details

Accounting

Voucher entries, day book, bank and cash accounts, payables, ledger reports

Counters

Dedicated bakery counter and juice counter with their own billing flows

Data and Synchronization

All data is stored in Supabase, a cloud database. This means:

  • Data entered on one device is immediately visible on all other devices at the restaurant.
  • If the internet goes down briefly, the system continues to work using local storage and will sync when connectivity is restored.
  • Data is never lost. Every bill, order, voucher, and salary record is permanently stored.
Chapter 02

Login and User Roles

How to access the system and what each role can do

Logging In

The login page is the first screen you see when you open the application. All staff members log in using a 4-digit PIN. There is no username to remember — only the PIN is required.

  1. Open the applicationGo to the restaurant's web address in any browser on any device.
  2. Enter your 4-digit PINTap the numbered buttons on screen or type the PIN using the keyboard.
  3. Press LoginThe system will identify you by your PIN and load the dashboard appropriate to your role.
Important Each PIN must be unique. Two staff members cannot share the same PIN. If a PIN is entered incorrectly, the system will reject it without any message about who the PIN belongs to, for security reasons.

Role-Based Permissions

The system has five roles. Each role has a specific set of pages and functions it can access. The Admin has full access to everything.

Role What They Can Access Typical Staff
Admin All modules without restriction: billing, menu, inventory, reports, staff, accounting, settings Owner, General Manager
Manager Tables, orders, billing, inventory, reports, menu, kitchen Floor Manager, Supervisor
Cashier Billing, orders, reports Counter Staff, Billing Staff
Waiter Tables, order taking, menu viewing Servers, Stewards
Kitchen Kitchen Display System only Cooks, Kitchen Staff

Logging Out

Click the logout button at the bottom of the left sidebar next to your name. You will be returned to the PIN login screen. Always log out when leaving the device unattended.

Chapter 04

Table Management

Managing the physical layout and status of your tables

Navigate to Sidebar - Tables to access the table management page. This page displays all tables in the restaurant laid out visually.

Understanding Table States

Every table has one of four states. The color and icon on each table card shows its current status. You can also see how long a table has been in its current state.

Seating Guests at a Table

  1. Click on a Free tableA panel will slide open on the right side of the screen.
  2. Set the guest countEnter the number of guests being seated at this table. This is important for the head count report.
  3. Click Seat GuestsThe table status changes to Occupied. You can now take their order.

Reserving a Table

  1. Click on a Free tableOpen the table details panel.
  2. Click Mark as ReservedThe table turns yellow and is marked reserved for an upcoming guest.
  3. When the guest arrivesClick the reserved table and click Seat Guests to convert it to occupied.

Adding or Editing Tables

Only the Admin can add, rename, or delete tables. To add a table, click the plus button at the top right. You can set the table number and capacity. Tables can also be reordered on screen to match the physical layout of the restaurant.

Tip You can filter tables on this page by status using the filter buttons at the top. Use the Occupied filter to quickly see which tables need attention.
Chapter 05

Order Taking

From seating to sending items to the kitchen

Navigate to Sidebar - New Order or tap any occupied table and click New Order. The order taking screen is the main working screen for waiters.

Screen Layout

  • Left Panel: Menu categories and items. Scroll through or search for items.
  • Right Panel: The current order (the KOT — Kitchen Order Ticket) showing items added, quantities, and running total.

Adding Items to an Order

  1. Select the tableAt the top of the order screen, choose which table this order is for.
  2. Browse or search the menuClick a category on the left to filter items. Use the search bar to find a specific item by name.
  3. Click an item to add itThe item appears in the order panel on the right with a quantity of 1.
  4. Select a variant if requiredIf an item has multiple variants (for example, Half or Full), a pop-up will appear asking you to select the correct variant.
  5. Adjust quantityUse the plus and minus buttons next to each item in the order panel to increase or decrease quantity.
  6. Add a note to an itemLong-press or click the note icon next to any item to add a special instruction such as No Onion or Extra Spicy. This note will print on the kitchen ticket.

Sending the Order to the Kitchen

When the order is complete, click the Send to Kitchen button at the bottom of the order panel. The system will:

  • Create a KOT (Kitchen Order Ticket) and send it to the Kitchen Display System.
  • Mark the table as Occupied with an active order.
  • Lock sent items so they cannot be changed without a manager override.

Adding More Items (Second Round)

If guests order more items after the first KOT has been sent, go back to the same table and click Add More Items. New items can be added and sent as a second KOT. The bill will combine all KOTs for that table.

Cancelling an Item

To remove an item from an already-sent order, a Manager or Admin must perform the cancellation. The system records who cancelled and at what time for audit purposes.

Important Items that have already been sent to the kitchen cannot be silently removed. The system keeps a log of all cancellations to prevent loss of revenue.

Chapter 07

Billing and Payment

Generating bills, applying discounts, accepting payment, and printing

Navigate to Sidebar - Billing. Billing can also be initiated directly from a table by clicking Generate Bill on an occupied table.

Generating a Bill

  1. Select the tableChoose the occupied table for which you want to generate a bill from the dropdown at the top.
  2. Review the billAll items from all KOTs for the selected table will be listed. Verify the items with the guest before proceeding.
  3. Apply discount if neededEnter a discount percentage or fixed amount in the discount field. The system will recalculate the total automatically.
  4. Select payment modeChoose how the guest is paying: Cash, Card, UPI, or Split (multiple modes).
  5. Enter amount receivedFor cash payments, enter the amount given by the guest. The system will calculate and display the change to be returned.
  6. Click Generate BillThe bill is finalized and the table status changes to Billing, then Free.

GST Calculation

GST is automatically calculated based on the rate assigned to each menu item. Restaurants typically apply:

GST RateWhen Applied
5%Most food items at standalone restaurants with turnover below Rs. 1.5 crore
12%Restaurants with air conditioning, seafood, or items served in five-star properties
18%Outdoor catering

The bill shows both CGST and SGST breakup as required by Indian GST law. The total GST is split 50/50 between CGST (Central) and SGST (State).

Note The GST rate for each item is set in Menu Management. Make sure the correct rate is assigned when adding new menu items.

Split Payment

If a guest wants to pay partly by cash and partly by card or UPI, select the Split payment option. Enter the amount for each mode separately. The total of all modes must equal the bill amount.

Printing the Bill

After generating a bill, a print-ready receipt appears on screen. Click the Print button to send it to the connected receipt printer. The receipt includes:

  • Restaurant name, address, and GSTIN
  • Table number, bill number, date, and time
  • Itemized list with quantities and prices
  • Subtotal, GST breakup (CGST + SGST), discount applied, and final amount
  • Payment mode used and change returned

Bill History

Navigate to Sidebar - Bill History. All bills generated are stored here permanently. You can search by date, bill number, or table. You can also view and reprint any old bill from this screen.

Menu Management

Adding, editing, disabling, and deleting menu items and categories

Navigate to Sidebar - Menu. Only Admin and Manager roles can access this page.

Page Layout

  • Left Panel: Category list showing all categories with item count for each.
  • Right Panel: Table listing all items in the selected category with their price, GST rate, and availability status.

Adding a New Menu Item

  1. Click Add ItemButton at the top right of the page.
  2. Fill in the detailsItem name, category, base price, and GST rate are required. Description, spice level, and special flag are optional.
  3. Set Veg or Non-VegToggle the switch to indicate whether the item is vegetarian. The green dot (veg) or red dot (non-veg) will appear on the order screen.
  4. Add Variants if neededIf the item has multiple sizes or options (for example, Half and Full, or Small, Medium, Large), add them in the Variants section. Each variant has its own name and price.
  5. Click SaveThe item appears in the menu immediately and is available for ordering.

Editing an Existing Item

Click the edit (pencil) icon next to any item. The same form opens with the current details pre-filled. Make your changes and click Save.

Enabling or Disabling an Item

Click the toggle switch icon in the Actions column. A green toggle means the item is available and will show on the order screen. A grey toggle means the item is disabled (86'd) and will not appear when taking orders. This is useful when an item is temporarily out of stock.

Deleting a Menu Item

Click the red trash icon in the Actions column. A confirmation dialog will appear asking you to confirm the deletion. This action is permanent. The item will be removed from the menu and will no longer be available for ordering. Historical bills that included this item are not affected.

Warning Deleting an item is irreversible. If the item is only temporarily unavailable, use the Disable toggle instead of deleting it. This way you can re-enable it later.

Managing Categories

Categories appear in the left panel. The order in which categories appear on the order screen matches the sort order assigned to each category. Contact the Admin to add a new category or change the sort order.

SectionWhat It Does

12.1 Understanding the Voucher System

In Indian accounting, every transaction is recorded as a voucher. A voucher is simply a record of one financial event — money received, money paid, goods purchased on credit, or a fund transfer. There are five voucher types:

Voucher TypeWhen to UseExample
Payment Any time money goes OUT of your bank or cash account Paying electricity bill, paying salary, paying a vendor for goods purchased earlier
Receipt Any time money comes IN to your bank or cash account Depositing cash sales to bank, receiving a refund from a supplier
Purchase Buying goods from a vendor on credit (you will pay later) Receiving 50 kg of chicken from a supplier with a 15-day payment term
Contra Moving money between your own bank and cash accounts Withdrawing Rs. 5,000 from the bank and putting it in petty cash, or depositing cash to the bank
Journal Any other adjustment entry that does not involve cash or bank directly Depreciation of equipment, writing off a bad debt
The Golden Rule of Vouchers Use a Payment voucher when actual money (cash or bank) changes hands going out. Use a Purchase voucher when goods arrive on credit and you have NOT yet paid. When you later pay the vendor, record a Payment voucher and select the vendor's name — this reduces the outstanding payable.

12.2 Payment Voucher — Step-by-Step

Use a Payment voucher for all expenses where cash or bank is debited (reduced).

  1. Go to Voucher Entry sectionClick the Voucher Entry button at the top of the Accounting page.
  2. Select Payment as the voucher typeClick the Payment button in the voucher type row.
  3. Set the dateThe date the payment was made. Default is today.
  4. Select the paying accountUnder "Paying From", choose the bank or cash account from which the payment is made.
  5. Select the expense headChoose the appropriate category: Salaries and Wages, Rent, Electricity, Gas, Raw Material Purchase, etc.
  6. If paying a vendor, select themIf this payment is to clear a vendor's outstanding balance, select the vendor from the "Paying to Vendor" dropdown. The system will reduce that vendor's payable balance automatically.
  7. Enter the amount
  8. Add narrationA brief description such as "October electricity bill" or "Salary paid to Mohan for September".
  9. Enter reference number (optional)The cheque number, UPI transaction ID, or invoice number.
  10. Click Save VoucherThe bank account balance is reduced by the payment amount. If a vendor was selected, their outstanding is also reduced.

12.3 Receipt Voucher — Step-by-Step

Use a Receipt voucher when money is coming INTO your bank or cash account from a source other than regular table billing (which is already tracked through the billing module).

  1. Select Receipt as voucher type
  2. Set date and enter amount
  3. Select the account receiving the moneyUnder "Received In", choose which bank or cash account is being credited.
  4. Add narrationFor example, "Cash deposit from Saturday sales" or "Refund received from LPG supplier".
  5. Click Save VoucherThe selected bank/cash account balance increases by the entered amount.

12.4 Purchase Voucher — Step-by-Step

Use a Purchase voucher when you receive goods from a vendor but do NOT pay at the time of delivery. This is a credit purchase — the money will be paid later.

Critical Distinction A Purchase voucher does NOT reduce your bank balance. It increases what you owe to the vendor. When you later pay the vendor, you record a Payment voucher and select the vendor name. That Payment will reduce both the bank and the vendor's outstanding balance.
  1. Select Purchase as voucher type
  2. Set the dateThe date the goods were received.
  3. Select the vendorfrom the "Purchase From" dropdown.
  4. Enter the total invoice amount
  5. Add narrationFor example, "50 kg chicken received from Fresh Farms" or "Monthly vegetable supply".
  6. Enter bill or invoice numberThe vendor's invoice number for cross-reference.
  7. Click Save VoucherThe vendor's outstanding payable increases by the entered amount.
Shortcut for Common Purchases If you record a purchase through the Inventory module (Purchase Entry) and select a registered vendor, the system automatically creates the Purchase voucher for you. You do not need to create it again in the Accounting module.

12.5 Contra Voucher — Step-by-Step

Use a Contra voucher only for transfers between your own accounts — from cash to bank, or from one bank account to another. This is neither an income nor an expense.

  1. Select Contra as voucher type
  2. Select Transfer FROMChoose the account being debited (reduced).
  3. Select Transfer TOChoose the account being credited (increased).
  4. Enter the amount and date
  5. Click Save VoucherOne account decreases, the other increases by the same amount. Total funds remain the same.

Deleting a Ledger Entry

If a voucher was entered incorrectly, click the red trash icon at the end of that row to delete it. A confirmation dialog will appear. Only Admin users should perform ledger deletions.

12.7 Bank and Cash Accounts

Navigate to the Bank and Cash section. Before you can record any Payment or Receipt voucher, you must set up at least one bank or cash account here.

Adding a Bank Account

  1. Click Add Account
  2. Enter account nicknameA short name you will recognize — for example, HDFC Current, SBI Savings, or Petty Cash.
  3. Select account typeCurrent, Savings, or Cash in Hand.
  4. Enter bank name and account numberOptional but recommended for reference.
  5. Enter opening balanceThe amount in this account as of the date you start using this system. This is your starting point. All subsequent transactions will be added to or subtracted from this balance.
  6. Click Save Account
Opening Balance is Critical The opening balance is the foundation of all future account statements. Enter the exact balance in your actual bank account on the day you start using this software. Check your bank statement or passbook for this number.

12.8 Vendor and Party Master

Navigate to the Vendors / Party section. This is the list of all your suppliers, wholesalers, and other parties from whom you purchase on credit.

Adding a Vendor

  1. Click Add Vendor
  2. Enter business nameThe legal or trading name of the supplier.
  3. Enter contact person, phone, and emailFor communication and reference.
  4. Enter GST numberThe vendor's GSTIN in the format 22AAAAA0000A1Z5. Required if you plan to claim input tax credit.
  5. Enter opening balanceIf you already owe money to this vendor before you started using this system, enter that amount here. This is the amount they supplied on credit in the past that you have not yet paid.
  6. Click Save Vendor

Vendor Account Statement

For each vendor in the list, the system shows:

  • Opening Balance: What you owed them when you started
  • Purchases: Total value of goods received on credit (Purchase vouchers)
  • Paid: Total payments made to them (Payment vouchers)
  • Outstanding: What you currently owe — Opening + Purchases minus Payments

12.9 Payables Ledger

Navigate to the Payables section. This is the creditors statement — a summary of what you owe to every vendor, sorted by outstanding balance from highest to lowest.

Reading the Payables Ledger

Status BadgeMeaning
Settled (Green)You do not owe this vendor anything. Balance is zero or negative (meaning they owe you).
Pending (Yellow)You owe this vendor a moderate amount — below Rs. 5,000.
High (Red)You owe this vendor more than Rs. 5,000. Pay promptly to maintain good supplier relations.

The Grand Total row at the bottom shows your total outstanding payable to all vendors combined. This is the figure you need to match against your cash and bank position to understand whether you can meet your obligations.

Practical Monthly Workflow for Accounting

1
Start of Month — Check Opening Balances

Verify that the closing balance from the previous month matches what is in your bank passbook and petty cash box.

2
Throughout the Month — Record Daily Transactions

Each time you pay a vendor, pay salaries, pay a utility bill, or receive money, record a voucher immediately. Do not let entries accumulate.

3
Whenever Goods Arrive — Record Purchase Vouchers

Every time a vendor delivers goods and you sign a challan or receive an invoice, record a Purchase voucher immediately.

4
End of Month — Verify the Payables Ledger

Compare the payables shown in the system against the statements or reminders received from each vendor. Discrepancies indicate a missing entry.

5
End of Month — Reconcile Bank Statement

Compare the current balance shown in the Bank and Cash section against your actual bank statement. If they do not match, check the Day Book for missing or duplicate entries.

Chapter 13

Counter Operations

Bakery Counter and Juice Counter — independent billing flows

Bakery Counter

Navigate to Sidebar - Bakery Counter. The bakery counter has its own dedicated billing interface for over-the-counter sales of baked goods.

Making a Bakery Sale

  1. Browse bakery itemsAll items tagged as Bakery type appear in the counter. Items are shown by category with current availability.

Shift Management

Opening and closing shifts for cash reconciliation

Navigate to Sidebar - Shift. Shift management is used to track cash at the start and end of each working day or each shift.

Opening a Shift

  1. Click Open Shiftat the start of the day or shift.
  2. Enter opening cash amountCount the cash in the till (cash drawer) and enter the exact amount.
  3. Click Start ShiftThe shift begins. All transactions from this point are tracked under this shift.

Closing a Shift

  1. Click Close Shiftat the end of the day.
  2. Enter actual closing cashCount the cash physically in the till.
  3. System shows expected cashOpening cash plus all cash sales during the shift minus any cash payments made.
  4. Verify the differenceIf actual cash is less than expected, investigate missing cash. If it is more, check for recording errors.
  5. Click Close ShiftThe shift report is saved with both expected and actual amounts for the manager to review.

Chapter 16

Frequently Asked Questions

Common issues and their solutions

Billing and Orders

Q: The order screen is not showing the latest menu items. What do I do?

Refresh the browser page. If the issue persists, check the internet connection. The menu syncs from the cloud every time the page loads.

Q: A bill was generated with the wrong items. Can I cancel it?

Bills cannot be edited after generation. If the bill was generated in error, record a separate refund or adjustment. Contact the software support for void bill assistance.

Q: The Reports page shows different revenue for "Today" and "This Month" even for today's date. Why?

This was a known issue that has been fixed. The system now uses complete pagination to fetch all bills, so both figures should be consistent. If you still see a discrepancy, it may be a time zone difference. Ensure the device time is set correctly.

Q: Can two waiters use the system at the same time?

Yes. The system is designed for simultaneous multi-user access. Multiple devices can be logged in and taking orders at the same time. All data is synchronized in real time.

Accounting

Q: I entered a Purchase voucher but the bank balance did not change. Is that correct?

Yes, that is correct. A Purchase voucher represents a credit purchase — goods received but not yet paid for. Only when you record a Payment voucher (paying the vendor) will the bank balance decrease.

Q: My Day Book total Debit and Credit are not equal. What does that mean?

An unequal Day Book indicates either a missing entry or an incorrect entry. Review the filtered Day Book for the period in question. Common causes include a Payment voucher recorded without a corresponding vendor payable reduction, or a manually entered amount with a typo.

Q: How do I record cash sales deposited to the bank?

Record a Contra voucher. Transfer FROM the Cash in Hand account TO the Bank account for the deposit amount. This correctly reduces the cash in hand and increases the bank balance.

Q: Can I delete a wrong ledger entry?

Yes. In the Day Book, click the red trash icon next to the incorrect entry and confirm deletion. Then re-enter the correct entry using a new voucher. Only Admin users should delete ledger entries.

Staff

Q: A staff member forgot their PIN. How do I reset it?

Go to Staff Management, click the edit icon for that staff member, and enter a new 4-digit PIN. Click Save Changes. The new PIN is active immediately.

Q: Can a staff member see their own salary records?

No. The Salary tab in Staff Management is only visible to Admin role users. Regular staff cannot access payroll information.

Chapter 17

Glossary of Accounting Terms

Key terms used in the Accounting module explained in simple language
TermPlain Language Explanation
Debit (Dr) An entry that reduces what the account holds. For a bank account, a Debit means money went out. For a vendor account, a Debit means you made a payment to them (reducing what you owe).
Credit (Cr) An entry that increases what the account holds. For a bank account, a Credit means money came in. For a vendor account, a Credit means you received more goods on credit (increasing what you owe them).
Payable Money you owe to a vendor or supplier. Also called a creditor or sundry creditor in Indian accounting.
Receivable Money someone owes to you. Not currently tracked in this system as restaurant sales are immediate (no credit to customers).
Opening Balance The amount in an account at the start of using the system. Think of it as the starting point from which all future transactions are measured.
Narration The description or note you add to a voucher. Write narrations clearly so anyone reading the Day Book can understand what the entry is for without needing to ask.
Ledger A permanent record of all financial transactions in chronological order. The Day Book in this system is the ledger.
Voucher A document (or record) that authorizes and records a financial transaction. In this system, you create vouchers through the Voucher Entry screen.
KOT Kitchen Order Ticket. The document (digital in this system) that communicates what the kitchen needs to prepare for a table.
CGST Central Goods and Services Tax. Half of the total GST collected goes to the central government.
SGST State Goods and Services Tax. The other half of GST collected goes to the state government.
GSTIN Goods and Services Tax Identification Number. Your restaurant's unique GST registration number, which must appear on all tax invoices.
Contra Entry A transaction that involves only your own accounts — for example, moving money from one bank account to another, or depositing cash to the bank. It is neither income nor expense.
Creditor / Sundry Creditor A business or person you owe money to — typically a supplier. Listed in the Payables section of the Accounting module.
Bank Reconciliation The process of comparing the bank balance in the system against the actual bank statement to confirm they match. Should be done at least monthly.
Advance Payment Money paid to a staff member before their regular salary date. Tracked separately in the Salary module so it can be deducted from the next salary payment.
